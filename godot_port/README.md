# Godot Port Starter

This folder contains a starter Godot 4 project to help migrate the browser-based JavaScript game into a native Godot workflow. It is intentionally minimal so you can open it in the Godot editor, point it at the existing art/sound assets, and reimplement gameplay.

## Project contents
- `project.godot` — Base Godot 4 project configuration with the main scene set to `scenes/Main.tscn`.
- `scenes/Main.tscn` — A simple `Node2D` scene that shows a placeholder label and attaches `scripts/main.gd`.
- `scripts/main.gd` — Minimal script that prints a status message when the scene loads. Use this as the entry point for recreating the JavaScript game flow.
- `assets/` — Empty placeholder directory for images and audio you import from the browser version.

## How to use
1. Open the folder `godot_port/` in Godot 4.x.
2. Set the correct renderer in **Project Settings** if needed (default is `forward_plus`).
3. Add assets from the browser version into `godot_port/assets/` (images, audio) or point resources to existing files.
4. Rebuild UI and logic in GDScript or C#:
   - Recreate menu/layout logic from `index.html`, `main.js`, and `src/ui/` as Godot scenes (e.g., `Control` nodes with buttons and labels).
   - Port world/map generation from `src/world/` and `src/main/` into scripts attached to your main scene.
   - Handle state management from `src/state/` using Godot `Nodes` or autoloaded singletons.
5. Replace `Main.tscn` with your own scene tree that mirrors the browser UI. Keep `project.godot` pointing to your main scene.
6. Run the project to verify assets import correctly; Godot will generate `.import` files automatically.

## Notes
- This starter does **not** implement gameplay; it only provides a valid Godot project structure and placeholder entry point.
- If you need to reference browser assets without copying, configure `res://` paths to point at shared directories or add them as symbolic links.
- Godot will import assets on first load, so you may see `.import/` metadata generated by the editor.
